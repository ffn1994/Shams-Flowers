# 🌸 شمس فلاورز — Shams Flowers

واجهة موقع شمس فلاورز: ورد وباقات وتنسيقات وديكور مناسبات في الكويت.
الصفحات الثلاث جاهزة: الرئيسية، الباقات (الكتالوج)، وتواصل معنا — مع الهيكل العام ونظام التصميم.

## التقنيات

| الأداة | الاستخدام |
| --- | --- |
| Vite + React (JavaScript) | أساس المشروع |
| Tailwind CSS v4 | التنسيق ونظام التصميم |
| React Router v7 | التنقل بين الصفحات |

## التشغيل

```bash
npm install
npm run dev      # بيئة التطوير
npm run build    # بناء نسخة الإنتاج
npm run preview  # معاينة نسخة الإنتاج
npm run lint     # فحص الكود
```

## نظام التصميم

كل التوكنز معرّفة في `src/index.css` داخل `@theme`، وتقدر تستخدمها مباشرة كـ Tailwind classes.

### الألوان

| المجموعة | الاستخدام | أمثلة |
| --- | --- | --- |
| `brand-50` → `brand-900` | الماجنتا/الوردي الأساسي من الشعار. الأساسي `brand-600` = `#C2185B` | `bg-brand-600` `text-brand-700` |
| `cream-50` → `cream-300` | الخلفيات الكريمية والبيضاء | `bg-cream-100` `border-cream-300` |
| `leaf-100` / `leaf-500` / `leaf-700` | لمسة خضراء للأوراق | `text-leaf-700` |
| `ink` / `ink-muted` / `ink-faint` | ألوان النصوص | `text-ink` `text-ink-muted` |

### الخطوط

- `font-sans` → **IBM Plex Sans Arabic** (الخط الأساسي للعربي).
- `font-display` → **Playfair Display** (للاسم الإنجليزي واللمسات اللاتينية).
- الخط ما عنده وزن ٨٠٠، فـ `--font-weight-extrabold` مضبوط على ٧٠٠ عشان المتصفح ما يزوّر الوزن.
- `text-hero` مقاس العناوين الكبيرة.

### المسافات والحواف والظلال

- `p-gutter` هامش جانبي موحّد، `py-section` ارتفاع القسم، `h-header` ارتفاع الهيدر.
- `rounded-petal` و `rounded-bloom` للحواف الناعمة.
- `shadow-soft` و `shadow-lift` للظلال الوردية الخفيفة.

### الكلاسات الجاهزة

`btn` · `btn-primary` · `btn-outline` · `btn-ghost` · `card` · `label` · `field` · `nav-link` · `nav-link-active` · `shell` · `section` · `bg-petal-gradient` · `text-brand-gradient`

مثال:

```jsx
<section className="section">
  <div className="shell">
    <button className="btn-primary">اطلب الحين</button>
  </div>
</section>
```

## الصفحة الرئيسية

أقسامها بالترتيب:

1. **الهيرو** — العنوان، وصف مختصر، زر تصفح الباقات وزر واتساب، وثلاث نقاط عن التوصيل.
2. **المميزات** — أربع بطاقات: التوصيل، الورد الطازج، التنسيق حسب الطلب، ديكور المناسبات.
3. **المناسبات** — مواليد، تخرج، أعياد ميلاد، استقبالات وأعراس.
4. **باقات مختارة** — ست تنسيقات من الكتالوج، كل وحدة بمناسبتها وسعرها وزر طلب على الواتساب.
5. **قسم الثقة** — "توصيل لجميع مناطق الكويت" مع نبذة عن المحل.
6. **كيف تطلب** — ثلاث خطوات.
7. **دعوة أخيرة** — بانر واتساب واتصال.

النصوص في `src/data/home.js` والتنسيقات في `src/data/packages.js` — عدّل الملفين وتتحدث الصفحة، ما يحتاج تلمس الكومبوننتات.

## صفحة الباقات (`/bouquets`)

- **١٦ تنسيقة** موزّعة على أربع مناسبات: مواليد، تخرج، حفلات، استقبالات.
- **أزرار تبديل المناسبة** فوق الشبكة، مع عدد التنسيقات في كل مناسبة.
- المناسبة **محفوظة بالرابط** (`/bouquets?category=graduation`)، فتقدر تنسخ الرابط وترسله، وبطاقات المناسبات بالصفحة الرئيسية تفتح المناسبة مباشرة.
- كل بطاقة فيها الصورة والمناسبة والاسم والسعر وزر **"اطلب الآن"** يفتح الواتساب برسالة جاهزة فيها اسم التنسيقة.
- التنسيقات الكبيرة (مدخل القاعة، ممر الاستقبال) تظهر **"حسب الطلب"** بدل السعر.

لإضافة تنسيقة: أضف عنصر في `packages` داخل `src/data/packages.js` وحدّد `category`. خلّ `featured: true` إذا تبيها تظهر بالصفحة الرئيسية.

## صفحة التواصل (`/contact`)

- **قنوات التواصل**: الواتساب (القناة الأساسية)، الاتصال، وإنستغرام — كلها تسحب البيانات من `src/siteConfig.js`.
- **نموذج طلب** يجمع الاسم والمنطقة والمناسبة والتنسيقة والتاريخ والملاحظات، ويحوّلها **رسالة واتساب جاهزة** مع معاينة للنص قبل الإرسال. الاسم والمنطقة مطلوبين، وزر الإرسال ما ينفتح قبلهم.
- **ما فيه سيرفر ولا قاعدة بيانات** — الزر رابط `wa.me` عادي، فما يحتاج باك إند ولا يوقفه حاجب النوافذ.
- قائمة التنسيقات داخل النموذج تتفلتر حسب المناسبة المختارة.
